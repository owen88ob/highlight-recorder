Features

为游戏而生,也为体验较真

不是"再录一个录屏软件"。它只做一件事,并把这件事做到极致:让保存高光这个动作,快到不打断你的下一波团战。

⏪

时光倒流式录制

环形缓冲常驻内存,只留最近 N+2 秒。按下保存的瞬间,从最近的关键帧切片拼接——不用提前开录,也不会存下整场对局。

🎈

悬浮球随叫随到

全屏游戏之上依旧可点。可拖动、松手自动贴边、透明度可调,呼吸红点提示录制状态。单击保存,长按停止。

⚡

硬件级性能

VirtualDisplay 直送 MediaCodec 输入面,全程零 Bitmap、零帧拷贝;编码声明 best-effort 为游戏让路。720p30 下额外占用仅几个百分点。

🔊

音画同录

内录游戏原声(AudioPlaybackCapture)或麦克风解说,AAC 混轨,保存时按视频起点自动对齐。

🛡️

稳字当头

前台服务 + 常驻通知;低电量、低内存自动降码率并提示,内存危急时体面暂停。被系统回收后自动尝试恢复。

🎛️

参数全可调

回退时长 / 分辨率 / 帧率 / 码率 / H.264·H.265 / 音频来源,实时显示内存与体积预估,改完即生效。

Getting Started

四步,存下第一个高光

安装并授权

首次打开引导页,逐项授予悬浮窗、通知等权限,每步都有"为什么需要它"的说明。

开始循环录制

主页一键开始,系统弹窗确认一次即可。此后 App 在后台静默缓冲,你可以忘掉它。

打出高光,点一下

五杀?神钩?单击悬浮球,最近 30 秒(可设)立刻在后台封装为 MP4,游戏零打断。

回放与分享

视频库内查看缩略图、时长与大小,一键播放、分享给队友,或导出到相册。

Under the Hood

环形缓冲 + GOP 对齐,如何做到不花屏

编码输出按实际到达的 IDR 关键帧切成 1 秒分片,容量固定逐出;保存时起点必为关键帧,PTS 重定基为 0——这是回放即点即播、首帧不花的根本原因。
